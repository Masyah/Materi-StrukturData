Deques¶

Deque atau Double Ended Queue adalah versi umum dari struktur data Queue yang memungkinkan penyisipan dan penghapusan di kedua ujungnya. Berikut adalah contoh program deque dalam berbagai bahasa.

Operasi-operasi yang terdapat pada Deques antara lain :

  • deque (), inisialisasi struktur data deque kosong
  • addFront (data), penambahan data baru di ujung front pada deque
  • addRear (data), penambahan data baru di ujung rear pada deque
  • removeRear (), penghapusan data pada ujung rear
  • removeFront (), penghapusan data pada ujung front
  • isEmpty(), pengecekan apakah deque dalam keadaan kosong
  • size (), informasi jumlah data yang terdapat pada deque

Struktur data Deques ini direpresentasikan dengan List, dimana: indeks awal list, yaitu indeks ke-0, adalah posisi front pada deques indeks akhir list, yaitu indeks terakhir, adalah posisi rear pada deques Oleh karena itu, penambahan data baru pada posisi front dapat dilakukan dengan method insert() pada posisi ke-0. Sedangkan penambahan data baru pada posisi rear dapat dilakukan dengan method append , yang merupakan penambahan data baru pada list di posisi terakhir. Sedangkan penghapusan data pada posisi front dapat dilakukan dengan method pop() pada posisi ke-0, sedangkan penghapusan data pada posisi rear dilakukan dengan method pop()

from collections import deque

def cek_palindrome(teks):
    teks_bersih = teks.lower().replace(" ", "")
    
    dq = deque(teks_bersih)
    
    while len(dq) > 1:
        huruf_depan = dq.popleft() 
        huruf_belakang = dq.pop()  
        
        if huruf_depan != huruf_belakang:
            return False
            
    return True

# --- DEFINISI FUNGSI DEQUE ---
def createDeque():
    return []

def addRear(dq, item):
    dq.append(item)

def removeRear(dq):
    return dq.pop()

def removeFront(dq):
    return dq.pop(0)

def size(dq):
    return len(dq)

# --- KODE ANDA YANG SUDAH DIRAPIKAN ---
def cekPalindrom(string):
    palindrom = createDeque()
    for huruf in string:
        addRear(palindrom, huruf)
        
    cek = True
    while size(palindrom) > 1:
        a = removeRear(palindrom)
        b = removeFront(palindrom)
        
        if a != b:
            # Begitu nemu yang beda, langsung set False dan hentikan loop (break)
            cek = False
            break
            
    return cek

print(cekPalindrom('katak'))    # Output: True
print(cekPalindrom('taat'))     # Output: True
print(cekPalindrom('dia'))      # Output: False

def simulasi_undo():
    # Inisialisasi stack kosong
    stack = []
    
    aksi_input = [("ketik", "A"), ("ketik", "B"), ("ketik", "C"), ("undo",)]
    
    print("Memulai simulasi...")
    
    for aksi in aksi_input:
        perintah = aksi[0]
        
        if perintah == "ketik":
            karakter = aksi[1]
            stack.append(karakter)  # Operasi PUSH
            print(f"Aksi: Ketik '{karakter}' -> Isi Stack saat ini: {stack}")
            
        elif perintah == "undo":
            if len(stack) > 0:
                terhapus = stack.pop()  # Operasi POP
                print(f"Aksi: Undo -> Menghapus '{terhapus}'. Isi Stack saat ini: {stack}")
            else:
                print("Aksi: Undo -> Gagal, stack kosong!")

    output_akhir = "".join(stack)
    print("\n" + "="*20)
    print(f"Output akhir: {output_akhir}")
    print("="*20)

# Menjalankan program
if __name__ == "__main__":
    simulasi_undo()
